Panduan penggunaan

Petunjuk sederhana untuk pengguna baru.

1. Isi profil dan materi

Pilih jenjang, kemampuan, mata pelajaran, topik, dan tempelkan materi jika ada. Kolom bertanda * wajib diisi.

2. Pilih mekanik gim

Gunakan katalog untuk melihat fungsi, tingkat kompleksitas, penilaian, dan batasan tiap mekanik. Multiplayer, speech recognition, dan simulasi kompleks mungkin memerlukan layanan atau kode tambahan.

3. Generate dan periksa

Buka langkah 7, periksa ringkasan, lalu klik Generate Prompt. Anda dapat mengedit prompt hasilnya sebelum menyalin atau mengunduh.

4. Buat gim dengan AI coding

Salin prompt ke layanan AI coding. Minta kode lengkap, simpan sebagai HTML jika satu file, buka di browser, lalu uji semua tombol, jawaban, skor, dan tampilan di perangkat sasaran.

5. Simpan dan ekspor

Simpan proyek untuk menyimpan konfigurasi dan prompt di akun Anda. Ekspor JSON untuk membuat cadangan.

Penting: jangan masukkan data pribadi murid. Periksa ketepatan materi, sumber, kunci jawaban, aksesibilitas, dan keamanan sebelum digunakan.
